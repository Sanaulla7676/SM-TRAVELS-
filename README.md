# SM Travels Review Hub

Mobile-first blue luxury review-copy hub for SM Travels. The site lists 12 services and opens three clearly labelled sample review drafts for each service. Includes the floating cat mascot artwork and copy buttons.

## Run locally
Open `index.html` in a browser. Keep `service.html`, `site.css`, `services.js`, and `cat-mascot.jpg` in the same directory.

> Review copy is sample text, not verified customer testimonials.
