# SM Travels Vehicle Fleet Review Hub

Mobile-first royal-blue review hub matching the existing SM Travels visual direction. The mobile home header uses the looping muted video, while the review pages retain their existing hero artwork and styling.

## Navigation
1. Select one of the five fleet categories.
2. Select a vehicle sub-service.
3. Open its three review drafts. The copy button copies the selected text and then redirects to the configured Google Reviews URL.

## Fleet coverage
- Cars: Sedan – Dzire / Etios (4 Seater), Ertiga (7 Seater), Innova Crysta (7+1 Seater)
- Tempo Travellers: 12+1 Seater – AC / Non-AC, 13+1 Seater – AC, 14 Seater Tempo Traveller
- Force Urbania: 12 Seater, 16+1 Seater
- Mini Buses: 21, 25, 33 and 35 seater options
- Luxury Coaches: 40 Seater Volvo Coach, 45 Seater Bus, 49/50 Seater Bus

Review text is sourced from the supplied SM Travels Vehicle Fleet PDF and is draft material, not verified customer testimonials.
